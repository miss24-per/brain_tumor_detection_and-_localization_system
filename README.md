# Brain Tumor Detection and Localization System

This project uses Deep Learning and Explainable AI techniques to detect and localize brain tumors from MRI images.

## Technologies Used
- TensorFlow
- MobileNetV2
- Grad-CAM
- OpenCV
- Streamlit

## Features
- MRI image upload
- Brain tumor classification
- Tumor localization using Grad-CAM
- Interactive web application

## Tumor Classes
- Glioma
- Meningioma
- Pituitary
- No Tumor

## Model Accuracy
~90% validation accuracy

## Run Project

```bash
streamlit run app.py
